# 人设类型学合测 · 轴向版

八维（功能轴 + 主辅先后）× 九型（动机三选一 + 加赛）× 本能（最像 / 最不像）的静态测试页。版式走「星图」：深靛蓝夜空、金色星线、三圈轨道结果星图（动态星轨与三体运动）、天文环入场动画；按钮按哆来咪发嗦拉发声（WebAudio 合成，右上角可关闭）。

可做完整合测，也可只做「单测八维」「单测九型」或「单测本能」。单测只出对应题目、进度、结果和分享图，不会给没做过的模块编造结果。切换或重开一种模式会清空该次作答，避免答案串档。

- 在线地址：https://wr050429.github.io/renshe-typology-test/
- 作答方式：一次一题。普通题选中后自动翻到下一题；本能题先选「最像」，再选「最不像」（可选）才翻页；随时可以回上一题改答案，答完才出结果页。
- 题量：完整合测 101 题（八维 47、九型 36、本能 18）。九型另有 108 道型间加赛，覆盖全部 36 组型对，只在分差不足时出现，用来分胜负，不改选中率。
- 详细解读：免费，无付费墙。九型九份原创档案（核心动机与恐惧、常用应对、优势与代价、压力下的常见表现、易混型差别、翼型差异、自我观察建议）。八维与本能也有对应可读解释。结果页把「本次测量」和「理论档案」分开；未锁定、分差小或题量不足时会标明暂定，不强行判定翼型或三元。分享图只保留测量结果，不含长文。
- 本页是人设与类型学讨论工具，不是临床诊断，也不是经过标准化的心理量表。解读用来对照自观，不是对性格的实证结论，更不能代替专业帮助。结果只在你自己的浏览器里计算和生成，不会上传到仓库或服务器，也不会在本机留存答题记录；刷新或重置后就没有了。
- 分享图：测完点「生成分享图」，会在浏览器里画出一张 1080 宽（2 倍清晰度）的结果标本图，可以下载、用系统分享发出去，或者长按 / 右键保存页面上的预览图。
- `index.html` + `app.js` 是构建产物，直接由 GitHub Pages 提供。
- 源码在 `src/`：`model.ts`（题库、计分、模式与结果归纳）、`profiles.ts`（详细解读）、`app.tsx`（页面、星图与分享图）、`kit.tsx`（外层页面壳）、`main.tsx`、`starfield.tsx`（动态星空背景）、`sound.ts`（WebAudio 合成音效与六音音阶）。
- 安装与构建：`npm i`，然后 `npm run build`（或 `npx esbuild src/main.tsx --bundle --minify --jsx=automatic --outfile=app.js`）。
- 测试：`npm test`（Node 静态测试，不打开浏览器）。覆盖各模式题量与可完成性、结果/分享不泄漏未测模块、九型曝光与加赛全覆盖、旧题兼容、暧昧结果不假确定、九型九份档案齐全、星图与音效文件未被改动。
